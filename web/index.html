label features:

Translating a visual novel is easy to start and hard to finish.

"Why does chapter 3 crash?"

One missing {/i} breaks a scene.

Tags, [variables] and brackets live inside the text. Aside compares every translation with its original and tells you before a player sees it.

"Did anyone proofread file 41?"

You lose track of what is done.

Thousands of lines, many sessions, maybe several people. Aside keeps a proofreading state per line, file and group, with history and a diff.

"Why is this menu still English?"

The generator misses texts.

Strings in show text, input prompts and titles in variables stay untranslated. Aside finds what the generator skipped and lets you review it.

The whole translating workflow. Free.

Checks that know Ren'Py

Every line is compared with its original: text tags, variables, brackets, length, and whether it still fits the dialogue box when drawn with the game's own font. Language packs add the rules of your language, like typographic quotes or repeated words.

# game/tl/czech/ep1_arrival.rpy
translate czech ep1_arrival_5c1e2a:
    # mira "{i}Hey!{/i} Welcome back, [player_name]."
    mira "{i}Hej!{/i} Vítej zpátky, [player_name]."  ✓ tags ✓ vars ✓ fits
    # mira "Did you bring the {b}letter{/b}?"
    mira "Přinesl jsi ten {b}dopis?"            ✗ {/b} missing

Scene preview

The background and the pictures shown over it, with the game's fonts, next to the line you translate. Works best on games built from whole-scene pictures.

History and diff

Every version of every line and the difference between them. Undo is one click away, backups are made before every write.

Quick modes

Film layouts for fast translating and proofreading. With a search active you get "result 3 of 16", arrow keys for next and previous, whole-word search and filters.

Glossary and spelling hints

Character names are imported from the game, terms are checked in every line. Spelling hints come from your project's own vocabulary, so any language works.

Prepare any built game

Unpacks .rpa archives, decompiles scripts and lets the game's own engine generate the translation files. No SDK to install.

Missed texts

Finds strings the generator never saw (show text, input prompts, titles in variables) and adds the ones you approve to extra_strings.rpy.

Machine translation, your key

Translate a single line with DeepL, LibreTranslate or any OpenAI-compatible service. Off until you turn it on; the text goes straight to the service you chose.

Proofreading and progress

A proofreading state for every line, progress per episode, chapter or folder, a weekly goal and an estimate of when you will finish.

Language packs

The rules of your language are data: its letters, plural rules and typical words. Czech is the first pack; without one the neutral rules apply.

label how_it_works:

From a built game to a checked translation.

Prepare

Point Aside at a game. It unpacks the archives, decompiles the scripts and lets the game's own engine write the translation files into game/tl/.

The window for this comes with the next update

Translate

Line by line or in the quick film layouts, with the scene, the choices, the glossary and the history next to the text.

Check

Tags, variables, length and box fit on every line. Proofreading state and per-group progress show what is really finished.

Ship

Your translation is plain .rpy files in the game's tl folder, ready to zip and share. Pro can publish your progress to your site.

label privacy:

Your game and your translation stay on your computer.

Aside is a local desktop app. There is no account and nothing to sign in to.

  • Game folders are read-onlyAside writes only translation files and its own small data files. It never deletes a folder it does not own.
  • Every write is atomic, with a backup firstA crash or a full disk cannot leave a half-written file. Snapshots let you go back.
  • Plain files you can readShared project state lives in a small .aside folder next to your translation, bulky data in your app data folder.

Everything that leaves your computer written from the code

Telemetry, analytics, crash reportsnone

Not built and not planned. No update check either.

Your texts, file names, glossary, settingsnever sent to us

Nothing about your projects goes to the Aside server.

Machine translationonly if you turn it on

The line you translate, sent straight to the service you chose, with your own key. Needs your consent in Settings.

Licence checkPro only

The licence key, a random device id and the computer name you typed. No paths, no hardware ids.

Publishing progressPro, if you set it up

Percentages pushed with your own git to a repository you chose.

label origin:

It started with one translation.

Aside was not a product idea. It began as a tool for the Czech translation of Being a DIK: a fast editor, checks that catch broken tags, and a way to see what is proofread and what is not.

Then it was rebuilt for any Ren'Py game, tried on seven more, and ported to a fast desktop app with a Rust core. Every feature on this page exists because a real translation needed it.

Built by one translator who got tired of fixing tags by hand.

label faq:

Questions, answered.

Is Free really free? What is the catch?

The whole translating workflow is free: editor, checks, glossary, history, scene preview, choice menus, game preparation. No account, no ads, no upload. Pro sells time savers for big projects. If a feature is something every translator needs, it stays in Free.

Does Aside change my game?

No. Game folders are read-only for Aside. It edits translation files in your translation folder, after a backup, and everything can be undone.

Which games and Ren'Py versions work?

It was tried on 8 real games made with Ren'Py 7.4 and 8, with and without a tl folder and with .rpa archives, from 9 to 687 script files. Most Ren'Py games should open; games with unusual structures may need a look.

Is it only for Czech?

No. The interface is English and Czech is the first language pack. A pack is just data (letters, plural rules, typical words), so adding a language does not need a new app. Without a pack the neutral rules apply.

Do I need the Ren'Py SDK?

No. Aside unpacks archives itself and lets the game's own engine generate the translation files. The SDK is only used if you want to run Ren'Py's lint from inside Aside.

Does it need the internet?

No. Everything runs locally. Machine translation is optional, uses your own key and needs your consent. The Pro licence checks in now and then and keeps working offline for a grace period.

Can I translate a game that is not mine?

Aside works on your own copy of a game and writes only translation files. Whether you may publish a translation is up to the game's author, so ask them first.

What will Pro cost and how does the licence work?

One payment per major version, no subscription. The price is not set yet. A licence works on two computers and you can free one yourself. If a licence ever lapses, only Pro switches off; your projects and Free keep working.

Can a team work on one project?

Project state is stored in plain files with one log per author, merged when the project is opened or refreshed, so a shared folder is a natural start. Proper team features (assignments, roles, merging edits) are planned for Pro.

Why will Windows warn me about the installer?

The first builds are not code-signed yet. SmartScreen shows "Windows protected your PC"; choose More info and then Run anyway. Every file will be published with a SHA-256 checksum so you can verify it.

Windows only?

Windows comes first. The app is built with Tauri, so other systems are possible later, but nothing is promised yet.

Is Aside open source?

Not decided yet. The source is private for now. Whether the free part becomes open source or stays closed freeware is decided before the first public release. Pro stays closed either way, and Free stays free to use in both cases.

Is it affiliated with Ren'Py?

No. Aside is an independent tool for projects made with Ren'Py.
