Changelog

What changed, newest first.

Development history until the first public build. After that, every release gets its own entry with a version number.

Aside: the desktop app

In testingOctober 2026

The product gets its name, an installer and the licence system for Pro.

  • NewThe name Aside, the logo and the icons; the project folder is now .aside.
  • NewWindows installer: per user, no admin rights, tested automatically from the installed copy.
  • NewPro licences: activation with a key, two computers per licence, freeing a computer from the app.
  • NewNetwork client for machine translation in the new core.
  • FixedA freed computer stops using Pro at its next check, like a cancelled licence.
Under the hood
  • CoreLicence server with an admin page and automatic deployment.
  • CoreA cancelled licence stops working within hours.
  • CoreA written list of everything Aside sends over the network, kept up to date with the code.

A new core in Rust

October 2026

The whole engine rebuilt as a fast desktop program, checked step by step against the original so nothing changes under your hands.

  • FasterOne program instead of Python and a browser: the interface runs in its own window, without a local web server.
  • CoreParser, archives, checks, data files, projects, game tools and all 80 operations ported; 749 of 749 recorded cases match.
  • CoreCompared with the original on 8 real games: 8 968 read calls, 0 differences.
  • CoreThe Pro features as a separate program next to the app, with the same answers as before.

Translating gets context

Where it began

The BaDIK tool

A translation manager built for the Czech translation of Being a DIK: the editor, the checks for tags and variables, proofreading states, the glossary and history. Aside grew out of it.

aside

Translation manager for Ren'Py. Aside is an independent tool, not affiliated with Ren'Py.
