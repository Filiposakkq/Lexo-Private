      Small habits
      
Four fixes that save translators days.

    

    

      
Mark texts kept in variables
The generator only sees strings marked with _(). Show the variable with !t, and Ren'Py looks up its translation.


# invisible to translators
$ chapter = "The Lighthouse"
# translatable
$ chapter = _("The Lighthouse")
"Chapter: [chapter!t]"   ← translated

      
Wrap texts shown from code
Notifications, input prompts and show text lines are not dialogue. Mark them, or they stay in your language in every translation.


$ renpy.notify(_("Item added"))
$ name = renpy.input(_("What is your name?"))
show text _("Three days later...")

      
One sentence, one string
Word order changes between languages. Joined pieces cannot be reordered; a whole sentence with a variable can.


"You found " + str(n) + " coins."   # can't be translated well
"You found [n] coins."              # can

      
Leave room, and a font switch
Translations often run longer. Keep spare space in the dialogue box, pick a font with accented letters, and let translators change it for their language.


translate czech style default:
    font "fonts/NotoSans-Regular.ttf"
