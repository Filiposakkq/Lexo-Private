Which one

Pick by the job, not the logo.

Pick Aside if

You translate by hand and care how it reads.

Checks that never let a tag break, the scene and the choices next to the line, a clear proofreading state, history, and the texts the generator missed.

Pick a machine translation tool if

You want a rough version fast.

RenLocalizer or renpy-translator push a whole game through many engines, and can unpack and repack it as a mod.

Pick a web platform if

A large team works in the browser.

Weblate, Crowdin or Renquill give accounts, roles and a shared memory online, at the cost of uploading the texts.

Machine translateCheck and proofread in AsideShip

Many translators mix tools. Aside reads plain .rpy files, so it fits after any tool that writes them, and catches what a machine broke.
